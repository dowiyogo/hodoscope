# Optical photon root cause diagnostic

- Date: 2026-05-12
- Branch: feat/optical-photon-iteration1
- Starting commit: 287231bd8c10781b5ead52412b859d0128a5bfb9

## Objective

Diagnose and resolve why optical photons generated by `G4Scintillation` are visible in tracking verbose output but are not counted by `SiPMSD` (`nph=0` in the ROOT output).

## Main hypothesis

Los fotones ópticos se generan correctamente, pero mueren dentro de la barra centelladora porque la `G4LogicalSkinSurface` con finish `groundfrontpainted` aplicada a `Scint_LV` cubre las 6 caras de la barra, incluyendo la cara que acopla al SiPM. Adicionalmente, el SiPM está separado por 50 µm de aire del extremo de la barra y no existe `G4LogicalBorderSurface` que defina el acoplamiento óptico barra-aire-SiPM.

## Plan

1. Crear infraestructura de diagnóstico y registrar rama, commit, hipótesis y logs.
2. Crear un test unitario óptico aislado con una barra EJ-200 y un SiPM en contacto directo.
3. Construir y ejecutar el test unitario, verificando producción, transporte y detección de fotones.
4. Diagnosticar si el fallo está en producción, transporte óptico o detección en el SiPM.
5. Aplicar el fix mínimo primero en el test unitario y exigir una eficiencia detectada mayor a 5%.
6. Migrar el fix al detector real detrás del flag `/hodoscope/det/improvedOptical`, con default `false`.
7. Validar el detector real con una macro dedicada y análisis ROOT cuantitativo.
8. Escribir el resumen final con diferencias antes/después, archivos y próximos pasos.
